# student-report-card-system
A Python-based interactive student report card system with input validation, grading and performance statistics.
*STUDENT REPORT CARD SYSTEM*

A beginner Python project that generates student report cards using an interactive command-line interface.

*FEATURES*
• Accepts multiple student records.
• Validates the number of students (1–500).
• Collects student names and scores.
• Validates scores (0–100).
• Automatically assigns letter grades.
• Generates remarks based on student performance.
• Counts students who passed and failed.
• Displays the total number of students.

*GRADING SYSTEM*

80–100: A - Excellent
70–79: B - Very good
60–69: C - Good
50–59: D - Trying
40–49: E - Poor
0–39: F - Fail

*REQUIREMENTS*
• Python 3.x
• No external libraries required.

*HOW TO RUN*
1. Clone or download the repository.
2. Open the project folder in your terminal.
3. Run: `python main.py`
4. Follow the prompts to enter student information.

*CONCEPTS PRACTISED*
• Variables and data types
• User input
• Lists and nested lists
• For and while loops
• Conditional statements
• Input validation
• Type conversion
• Basic counting and calculations
